# 项目命名策划

## 定位与约束

- **当前定位**：脑力训练 / 认知训练平台
- **当前项目名**：`stroop-lab`（偏 Stroop 单一玩法）
- **扩展方向**：多游戏、多能力维度（注意力、反应、记忆、逻辑等）、可能包含统计、目标、社区等
- **命名目标**：不绑定单一玩法、可延展、好记、适合做产品/品牌名，技术名适合做仓库与包名

---

## 命名原则

1. **语义开放**：不锁定「Stroop」或「舒尔特」，能涵盖未来多种认知游戏与功能
2. **保留「Lab」可选**：现有名含 `-lab`，可延续「实验、练习、工坊」的联想
3. **中英皆宜**：英文作包名/域名，中文可作产品副标题或 slogan
4. **简短、可商标化**：2–3 音节为主，便于记忆与注册

---

## 候选方案

### 一、推荐首选

| 名称 | 包名/仓库名建议 | 含义与联想 | 优点 | 注意 |
|------|------------------|------------|------|------|
| **Cogni** | `cogni` / `cogni-lab` | 源自 cognition（认知），中性、专业 | 短、好记、天然覆盖「认知训练」；易延展（Cogni Play / Cogni Lab） | 需查商标/域名 |
| **MindGym** | `mindgym` / `mind-gym` | 大脑的「健身房」 | 直观、有画面感、适合多游戏/多模块 | 已有同名产品，若仅作内部或开源项目可用 |
| **Lumen** | `lumen` / `lumen-lab` | 光、洞察、思维清晰 | 气质好、不局限某类游戏；Lumen Mind / Lumen 脑力 | 需查商标/域名 |

### 二、备选

| 名称 | 包名/仓库名建议 | 含义与联想 | 适用场景 |
|------|------------------|------------|----------|
| **Cortex** | `cortex` / `cortex-play` | 大脑皮层，偏神经/科学感 | 想强调「科学训练」时 |
| **Synapse** | `synapse` / `synapse-lab` | 神经突触，连接与学习 | 偏极客/科学品牌 |
| **FocusForge** | `focus-forge` | 锻造专注力 | 偏「专注力」单一卖点时 |
| **Nexus** | `nexus` / `nexus-mind` | 枢纽、连接多游戏/多能力 | 强调「平台」「集合」时 |
| **CogLab** | `cog-lab` | Cognition + Lab 缩写 | 保留「实验室」、延续现有 lab 风格 |

### 三、延续「Lab」的变体

若希望保留与 `stroop-lab` 的延续感：

- **Cogni Lab** → 包名 `cogni-lab`（认知实验室）
- **Mind Lab** → 包名 `mind-lab`（心智实验室）
- **Think Lab** → 包名 `think-lab`（思维实验室）

---

## 推荐结论

- **首选**：**Cogni**（产品/品牌名） + **cogni-lab**（仓库/包名）  
  - 理由：短、好记、不绑定 Stroop，覆盖「认知训练」且易扩展；保留 `-lab` 与现有项目气质一致。
- **产品标题示例**：  
  - 中文：**Cogni · 脑力训练** 或 **Cogni 脑力训练平台**  
  - 英文：**Cogni – Brain & Cognitive Training**

---

## 落地时可修改的资产

确定名称后，建议统一修改（示例以 **Cogni / cogni-lab** 为例）：

| 位置 | 当前 | 修改后 |
|------|------|--------|
| `package.json` → `name` | `stroop-lab` | `cogni-lab` |
| `index.html` → `<title>` | `stroop-lab` | `Cogni · 脑力训练` 或 `Cogni – Brain Training` |
| Header / 首页标题 | 脑力训练平台 | Cogni 或 Cogni · 脑力训练 |
| 文档 / README | 项目名、描述 | 新名称与定位说明 |
| 仓库名（Git） | 视情况 | `cogni-lab` 等（需在 Git 托管侧重命名） |

---

## 小结

- 从「脑力训练平台 + 会持续扩展」出发，**Cogni** 最平衡：不绑定 Stroop、可涵盖多游戏与未来功能、简短可品牌化，技术侧用 **cogni-lab** 延续 lab 风格。  
- 若更倾向「健身房」隐喻或已有 MindGym 竞品考虑，可选用 **Lumen** 或 **Cortex** 作为替代方案。

确定名称后，可据此更新 `package.json`、`index.html`、Header/首页标题及 README 等。
